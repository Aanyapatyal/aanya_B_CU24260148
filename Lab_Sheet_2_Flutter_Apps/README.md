# Lab Sheet 2: Flutter UI Applications

This package contains 25 independent Flutter examples. Each `.dart` file is a complete `main.dart` source file for a small Flutter app; the app screens are kept intentionally simple for lab practice. Names, college details and sample content can be edited in the source.

## Run an example

1. Install Flutter and confirm `flutter doctor` completes the setup for your platform.
2. Create a Flutter project once: `flutter create lab_sheet_2`.
3. Copy one example file into `lab_sheet_2/lib/main.dart` (renaming it to `main.dart`), replacing the starter contents.
4. From the project folder, run `flutter run` and select an emulator or connected device.
5. To try another question, replace `lib/main.dart` with a different example file and run again.

These examples use only Flutter's built-in Material widgets and need no extra package. Image examples fetch a sample image from the internet; if the device is offline, an icon fallback is shown. The buttons are UI examples and do not perform actions unless the source is extended. The calculator file demonstrates the layout only; it does not calculate.
