# Lab Sheet 5: Flutter Lists, Grids and Dynamic UI

This package contains 17 independent Flutter examples. Each `.dart` file is a complete `main.dart` source file. The examples cover ListView, grids, Dart lists and model classes, state updates, and an interactive student record list.

## Run an example

1. Install Flutter and check setup with `flutter doctor`.
2. Create a Flutter project once: `flutter create lab_sheet_5`.
3. Copy one chosen `.dart` file into `lab_sheet_5/lib/main.dart`, replacing the starter file.
4. Open a terminal in the project folder and run `flutter run` with an emulator or device connected.
5. Replace `lib/main.dart` with a different example to run another question.

No additional packages are needed. In Question 17, enter all three student fields and tap Add student. Search filters by student name; use the delete icon to remove a record. Records are held in memory and clear when the app restarts.
