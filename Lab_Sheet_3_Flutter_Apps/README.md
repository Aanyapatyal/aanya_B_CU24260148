# Lab Sheet 3: Flutter Forms and Input

This ZIP contains 25 independent Flutter app examples. Each `.dart` file is a complete `main.dart` source file. Text fields, buttons and selection controls are interactive; calculation examples show their result on screen.

## Run an example

1. Install Flutter and check your setup with `flutter doctor`.
2. Create a Flutter project once: `flutter create lab_sheet_3`.
3. Copy one chosen `.dart` file into `lab_sheet_3/lib/main.dart`, replacing the starter file contents.
4. Open a terminal in `lab_sheet_3` and run `flutter run` with an emulator or device connected.
5. To run another question, replace `lib/main.dart` with another example file and run again.

No additional packages are required. For percentage and result programs, each subject mark is treated as being out of 100. The student result example uses 40% as the pass threshold; change it in the code if your course uses a different rule.
