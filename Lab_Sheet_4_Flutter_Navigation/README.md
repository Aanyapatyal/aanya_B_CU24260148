# Lab Sheet 4: Flutter Navigation and Multi-Screen Applications

This ZIP contains 25 independent Flutter examples. Each `.dart` file is a complete `main.dart` source file for a small app and demonstrates routes, Navigator push/pop, bottom navigation, drawers, or passing values between screens.

## Run an example

1. Install Flutter and check your setup with `flutter doctor`.
2. Create a Flutter project once: `flutter create lab_sheet_4`.
3. Copy one chosen `.dart` file into `lab_sheet_4/lib/main.dart`, replacing the starter file contents.
4. In a terminal opened in the project folder, run `flutter run` with an emulator or device connected.
5. Replace `lib/main.dart` with another example to try a different program.

No additional packages are required. Student and product values in the examples are sample data; edit them in the source for your own details.
